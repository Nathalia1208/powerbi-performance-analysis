# Power BI - Análise de Performance Publicitária

## Sobre o Projeto

Projeto desenvolvido como parte de um teste técnico para vaga de Análise de Performance / Analista de Dados Júnior.
O objetivo foi realizar o tratamento, modelagem e análise de dados relacionados a campanhas publicitárias de TV, Rádio e Digital utilizando Power BI.
O projeto envolveu etapas de:
* tratamento de dados no Power Query;
* modelagem dimensional;
* criação de métricas em DAX;
* desenvolvimento de dashboard analítico.
---
# Tecnologias Utilizadas
* Power BI
* Power Query
* DAX
---

# Etapas Desenvolvidas
## Tratamento dos Dados
* Separação e padronização das colunas
* Ajuste dos tipos de dados
* Correção de inconsistências estruturais dos arquivos CSV

## Modelagem
* Criação de modelo dimensional
* Implementação da dimensão `dim_campaign`
* Correção de relacionamentos muitos-para-muitos

## Dashboard

Desenvolvimento de dashboard analítico para acompanhamento de:

* Impressões
* Cliques
* Investimento
* CTR
* CPC
* CPM

Também foram realizadas análises por:

* Canal
* Região
* Programa
* Anunciante
* Evolução temporal
  
---

# Principais Desafios

* Tratamento inicial dos arquivos CSV
* Organização dos relacionamentos entre tabelas
* Estruturação do modelo para evitar ambiguidades analíticas
* Padronização dos dados para construção dos indicadores

---

# Observações

Durante as análises, foi identificada baixa variabilidade entre alguns indicadores, indicando possível utilização de dados sintéticos para fins do teste técnico.

Mesmo assim, o projeto permitiu aplicar conceitos importantes de:

* ETL
* Modelagem dimensional
* Business Intelligence
* Visualização de dados
